## 🎮 How It Works

### Gameplay Flow
1. **Home** → Click "START BATTLE"
2. **Choose Categories** → P1 selects, P2 selects different
3. **Choose Algorithms** → Pick from selected categories
4. **Provide Input** → Manual or auto-generated data
5. **Watch Battle** → Animated execution progress
6. **See Results** → Winner determined by performance

### Performance Metrics
- **Execution Time** - Measured in milliseconds
- **Memory Usage** - Measured in kilobytes
- **Scoring** - Combined score determines winner
